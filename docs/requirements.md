# 映画記録アプリ 要件

## 確定事項

### スコープ

- MVPは「記録」+「一覧」のみ

### ドメイン設計

- `person`:人物(監督・キャスト)。TMDbIDで一意
- `movie`:映画マスタ。`Credit`で`person`と紐付け(役割:監督/キャスト)
- `platform`:視聴サービス。DBルックアップテーブル。一般ユーザーは追加不可、自由記述なし、管理者(あなた)のみ追加

### 技術スタック

- バックエンド:Go
- フロント:Next.js
- スマホ:Flutter
- DB:PostgreSQL(将来Elasticsearch導入予定)
- 認証:アクセストークン+リフレッシュトークン

### 映画データ調達

- TMDb APIから都度取得 → 自分のDBに保存して正とする
- 自前クローラーは今は作らない(将来、TMDbで薄い領域が明確になったら検討)

### 記録項目

- 自動取得(TMDb):ジャンル、監督、キャスト、上映時間、公開年、製作国、言語、ポスター画像
- 手入力:タイトル(検索起点)、視聴日、メモ、スコア、視聴プラットフォーム、雰囲気タグ(固定・複数選択)
- カウンタ:視聴回数(累計のみ。再視聴時はカウントを+1するだけで、メモ/スコア/視聴日は上書きしない)

---

### Score

- 1〜5の数値のみ。各段階の意味・基準は言語化せず、感覚で付ける(保留のまま確定)

### Genre

- TMDbの19種類をそのままEnum化:アクション、アドベンチャー、アニメーション、コメディ、犯罪、ドキュメンタリー、ドラマ、ファミリー、ファンタジー、歴史、ホラー、音楽、ミステリー、ロマンス、SF、TVムービー、スリラー、戦争、西部劇

### MoodTagの定義(確定)

「どんな映画が見たい/どんな映画だったか」を一言で答える時に使う、映画のタイプを表す言葉。

- Genreとは別軸(客観的なジャンル分類と重複させない)
- あらすじ・設定の説明ではない
- 感情動詞ではなく「〜系」と言える名詞・形容詞的な言葉(例:「感動する」ではなく「感動系」)

### MoodTag一覧(確定・18個)

感動系、ダーク系、スタイリッシュ系、ハードボイルド系、シュール系、切ない系、爽快系、ノスタルジック系、壮大系、緊張感系、ほのぼの系、ミニマル系、実験的系、ロマンチック系、胸糞悪い系、ハートフル系、ビターエンド系、不条理系

### Platform初期リスト(確定)

- 世界規模:mubi、Netflix、Amazon Prime Video、Disney+、Apple TV+
- アメリカ:Max、Peacock、Paramount+、Criterion Channel、Shudder、Tubi、Pluto TV、Roku Channel、VRV
- イギリス:BBC iPlayer、Channel 4(All 4)、ITVX
- 日本:U-NEXT、Hulu、ABEMA、dアニメストア、Lemino、FOD、Paravi、WOWOWオンデマンド
- 視聴環境:映画館、DVD/Blu-ray、地上波/BS/CS放送、レンタル

### TMDb API連携フロー(確定)

1. タイトル検索欄でTMDb検索
2. 候補(タイトル・公開年・ポスター画像)から選択すると、監督・キャスト・ジャンル等が自動入力される。この内容は編集不可
3. 自分のDBに該当映画(TMDbID一致)が既にあればそれを使い、なければ新規保存
4. 検索で見つからない場合は「手動で入力する」を選び、すべての項目を自分で入力する(TMDbIDは持たず、内容は自由に編集可能)
